# 具身智能技术文献库

八个技术主题的文献检索入口，支持主题、关键词、年份、资料类型与原文存档筛选。同一工作可关联多个主题；跨主题检索时合并显示。

网页由 `index.html`、`style.css`、`library.js` 与 `catalog.json` 组成，直接通过 GitHub Pages 发布。论文原文存档由独立的 ChatGPT Sites 服务提供。

## 更新

`catalog.json` 为公开文献目录，不含本地文件路径、获取日志或私人批注。维护时在原有主题库修改书目数据，再运行工作区 `技术/在线文献库/维护/整理文献库.py` 重新生成目录。新增原件需先上传到原文服务并核对，再提交更新后的网页。
